О проекте

Beauty HH Parser - это специализированный инструмент для поиска специалистов бьюти-индустрии на hh.ru.

Технологии:

  • Backend: Python, Flask, Requests
  • Frontend: HTML5, CSS3, JavaScript
  • API: hh.ru API
  • Стили: Адаптивный дизайн, CSS Grid/Flexbox

Возможности:

  • Поиск парикмахеров, универсалов, барберов
  • Фильтрация по городам и опыту работы
  • Экспорт результатов в CSV
  • Статистика по требованиям
  • Актуальные данные с hh.ru
