Инструкция по запуску:
    1. Установите Python (если не установлен)
    2. Создайте структуру папок:
beauty-hh-parser/
├── app.py
├── hh_parser_beauty.py
├── requirements.txt
├── static/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── script.js
└── templates/
    ├── index.html
    ├── data.html
    ├── result.html
    └── info.html
    3. Установите зависимости:
pip install -r requirements.txt
    4. Запустите приложение:
python app.py
    5. Откройте браузер и перейдите по адресу:
http://localhost:5000


Как это работает:
    1. Пользователь заходит на главную страницу с информацией о сервисе
    2. Переходит на страницу поиска и заполняет форму
    3. JavaScript отправляет данные на сервер через API
    4. Flask принимает запрос и вызывает парсер
    5. Парсер обращается к hh.ru API и собирает вакансии
    6. Сервер обрабатывает данные и возвращает результат
    7. JavaScript отображает результаты в таблице с возможностью сортировки и фильтрации
    8. Пользователь может экспортировать данные в CSV


Особенности реализации:
✅ Полная интеграция Python и JavaScript через REST API
✅ Адаптивный дизайн для всех устройств
✅ Красивый интерфейс с иконками Font Awesome
✅ Сортировка и фильтрация таблицы на клиенте
✅ Экспорт в CSV для дальнейшей работы
✅ Сохранение настроек в localStorage
✅ Анимации и плавные переходы
✅ Детальная статистика по найденным вакансиям
